# Family Word of the Day — Dropbox Folder

This folder is where you paste each morning's fresh prophetic word from
Pastor Kiki Ocansey / Prophet Prince Amo David. The daily 8am AM task reads
the newest file here and rebuilds your family devotional page.

## Folder path (in your Dropbox)

`/L137/Daily Words/`

## What to name each day's file

`YYYY-MM-DD.txt` — for example:

- `2026-08-13.txt`
- `2026-08-14.txt`

The date in the filename is the date the family will study it.

## What to paste inside the file

Just the raw prophetic word from the WhatsApp group — no formatting needed.
The 8am task handles the rest (title, scripture parsing, tier explanations,
"Today I Will…" choices for each age group).

### Recommended structure (any of these work)

**Minimum (easiest — just paste the WhatsApp message):**

```
WALKING IN DIVINE POWER.

For the earnest expectation of the creature waiteth for the manifestation
of the sons of God.
Romans 8:19.

With power, you become an enviable personality...
[rest of the prophetic word]
```

**Cleaner (optional — add these tags anywhere in the file for perfect parsing):**

```
TITLE: Walking in Divine Power
SCRIPTURE: Romans 8:19
DATE: 2026-08-11

[paste the full word here]
```

## What happens each morning at 8am EDT

1. Task looks for the newest `.txt` file in `/L137/Daily Words/`
2. Reads the word, identifies title / scripture / lesson
3. Writes short tier explanations for teens, young adults, older adults, retired
4. Writes 4 "Today I Will…" practical choices for each tier
5. Rebuilds the family devotional page at the SAME URL you shared
6. Sends you an in-app notification with the fresh link, ready to paste in
   the WhatsApp family group

## If nothing gets posted (weekends, day off)

The task exits silently if no new file has appeared since the last run.
No spam, no empty pages. Yesterday's page stays live until you drop a new one.

## Language / ministry boundaries always enforced

- KJV Scripture only, quoted in full
- No Reddit, no New Age, no non-Christian sources
- Pastor's original message stays intact — no random additions
- "Repeat after me" declarations preserved word-for-word
- L137 = Luke 1:37 · Prophet Prince = Dominion Hour
